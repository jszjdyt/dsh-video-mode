# 视频生成模式

这个插件包只做一件事：往 Agent 预设注册表里插入一个自定义模式 `video`。

安装后，新建任务时在输入框的「模式」菜单里会出现 **视频生成模式**（归在「自定义」分组）。
选中它创建的会话：

- 人格是 OpenMotion 视频导演，默认按视频创作流程做事，不需要用户先提「用 OpenMotion」；
- 自带 bash / 文件读写 / 检索 / 后台任务 / 技能 / 待办 / 联网 / 交付文件 / 子代理 / 上下文压缩 / 计划模式；
- OpenMotion 的 `openmotion_*` 工具与 `openmotion-*` 技能由已安装的 OpenMotion Host 插件提供，
  这些工具本来就是全模式可见的，本模式把它们变成默认工作方式。

## 适用

- 「做个 30 秒产品宣传片」
- 「照这个链接的节奏复刻一条」
- 「用你们的模板改一版，换成我们的品牌」
- 「给这段脚本配图、配音、出成片」

## 不适用

- 通用编码、科学计算、论文写作 —— 请用标准模式；
- 定制 DSH 本身 —— 请用创造模式。
